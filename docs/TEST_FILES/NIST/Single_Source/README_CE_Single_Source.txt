Description:

The capillary electrophoresis (CE) training data which is hosted here was generated by a 3500xL Genetic Analyzer from Applied Biosystems with a 36 cm capillary array and POP-4 polymer. The 11 NIST Training Data (NTD) samples were amplified with four short tandem repeat (STR) multiplex kits according to manufacturer's protocol (with the only exception of a 15 second injection time): GlobalFiler and Y-filer Plus Kits (Thermo Fisher) and PowerPlex Fusion 6C and PowerPlex Y23 Systems (Promega).  The data files are provided as .hid files from the 3500xL instrument, as well as the bins, panels, stutter, and size standard .txt files for use in GeneMapper ID-X (v1.5 was used for analysis at NIST).
